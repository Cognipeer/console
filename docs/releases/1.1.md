# 1.1 line

May – June 2026.

A short line. Its two substantial releases added the audio and OCR services and
moved the whole dashboard onto the Cognipeer design system; the rest were
container packaging.

[[toc]]

## v1.1.8

*1 June 2026*

**Docker-in-Docker and Playwright in the image.** The prerequisites for the
Agent Sandbox and for browser automation to run inside a deployed container,
rather than only on a developer machine. The Agent Sandbox itself arrives in
[v1.2.0](/releases/1.2#agent-sandbox-and-gpu-pools).

## v1.1.6

*21 May 2026*

**Agent SDK 0.7.0**, with richer tool-detail handling — tool calls carry enough
detail to be displayed and debugged rather than appearing as an opaque step.

## v1.1.4

*21 May 2026*

**The Cognipeer design system.** Design tokens, typography and theming were
adopted across the dashboard, replacing ad-hoc styling. The palette was extended
to cover grays and dark neutrals, and `FormShell` — the full-screen form
container used for create and edit flows throughout Console — was moved into a
portal so it can render above everything else.

The service catalog was updated in the same release.

## v1.1.0

*20 May 2026*

**Audio and OCR.** Speech synthesis, transcription, translation and optical
character recognition became first-class services with their own routes, rather
than something you reached a provider for directly.

## Packaging releases

`v1.1.1`, `v1.1.2`, `v1.1.3`, `v1.1.5` and `v1.1.7` (21 May 2026) carried
container image changes only — Playwright installation, the Node 22 user setup,
and file ownership inside the image. No application changes.
